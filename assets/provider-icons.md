# Provider icon sources

The transparent silhouettes are embedded as SVG data URLs in `styles.css`, so no network requests or extra packaged assets are needed at runtime. Profile accents color the silhouettes; their geometry is unchanged.

- Claude: https://raw.githubusercontent.com/lobehub/lobe-icons/master/packages/static-svg/icons/claude.svg
- Codex: https://raw.githubusercontent.com/lobehub/lobe-icons/master/packages/static-svg/icons/codex.svg
- DeepSeek: https://www.deepseek.com/ — symbol path extracted from the header SVG; the wordmark is omitted.

Claude and Codex are provider marks distributed by the third-party Lobe Icons collection, not downloads from the providers' brand kits. Original provider marks remain the property of their respective owners. Lobe Icons is MIT licensed: https://github.com/lobehub/lobe-icons/blob/master/LICENSE
